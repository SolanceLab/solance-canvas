# Changelog

All notable changes to this project are documented here. This project follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-08-17

First public release. Extracted from a private application, with the private
parts removed: no database, no stored-key encryption, no auth layer, no house
branding.

### Worker

- **Seven providers behind one interface** — Google Gemini, xAI Grok, fal.ai,
  OpenAI, Stability, Agnes (gateway), Venice — each a module exporting the same
  small contract (`id`, `label`, `envKeys`, `generate`). Adding another is a
  module and a registry entry.
- **Four routes**: `POST /generate`, `POST /generate/result` (fal's async queue
  returns a pending ticket for slow models), `GET /image/:key`, `OPTIONS`.
- **Bring-your-own-key** — a caller may send `X-Provider-Key` per request; it is
  used for that one request, never stored, never logged, and redacted by value
  from provider error messages. Operator env keys are the fallback.
- **Optional operator auth** — set `AUTH_TOKEN` and both POST routes require
  `Authorization: Bearer …` (RFC 9110 case-insensitive scheme, constant-time
  comparison). Unset leaves them open, which is the documented dev default.
- **Configurable CORS** — `ALLOWED_ORIGIN` applied once at the boundary; unset
  means `*`.
- **Optional R2 storage** — off by default (`createNullStorage`); bind a bucket
  and generated bytes are taken into your own storage instead of pointing at a
  provider's disk. The response reports `persisted`, `image_stored` and
  `persist_error` so a caller can tell what actually happened.
- Provider-specific hardening carried over from production: fal poll URLs are
  host-allowlisted and refuse redirects, Gemini's key travels in a header rather
  than the query string, and error messages are redacted before they surface.

### UI

- `<Canvas />` and `<CanvasSettings />` — prompt, model picker, aspect ratio,
  resolution tier, reference images, and 50 style presets.
- **Per-provider key slots** stored only in the visitor's own browser
  (`localStorage`), masked, individually removable. A status-only read path
  makes it structurally impossible for the settings component to render a
  stored key.
- Prebuilt neutral-theme stylesheet (`ui/canvas.css`) — tokens plus exactly the
  utility classes the components use, no preflight, so importing it cannot
  reset a host application's styles. Follows `prefers-color-scheme`, or an
  explicit `data-canvas-theme` attribute.

### Docs & tooling

- [`docs/LESSONS.md`](docs/LESSONS.md) — six production failures that cost real
  images, and one near-miss caught in review.
- `demo/` harness (`npm run demo`) mounts the library exactly as a host app
  would.
- 72 tests, including a JSX compile gate so a broken component fails the suite.
